
# Rahvion: AI-Powered Robotics-as-a-Service

America's Personal IT Department. Enterprise-Grade Remote Technical Support for Your Home.

## Features
- RaaS Pricing & Memberships
- Personal IT Toolkit
- Responsive Design
- SEO Optimized React SPA

## Local Development
1. Install dependencies: `npm install`
2. Start development server: `npm run dev`

## Build for Production
Run `npm run build` to generate the production build in the `dist/` directory.

## Deployment
See `VERCEL_DEPLOYMENT.md` for detailed instructions on deploying to Vercel.

## Tech Stack
- React 18.2.0
- React Router 6.16.0
- Vite
- TailwindCSS 3.3.2
- shadcn/ui
- Framer Motion
